7. Liveness

While containerized applications are scheduled to run in pods on nodes across our cluster, at times the applications may become unresponsive or may be delayed during startup. Implementing Liveness and Readiness Probes allows the kubelet to control the health of the application running inside a Pod's container and force a container restart of an unresponsive application.

If a container in the Pod has been running successfully for a while, but the application running inside this container suddenly stopped responding to our requests, then that container is no longer useful to us. This kind of situation can occur, for example, due to application deadlock or memory pressure. In such a case, it is recommended to restart the container to make the application available.
Rather than restarting it manually, we can use a Liveness Probe. Liveness Probe checks on an application's health, and if the health check fails, kubelet restarts the affected container automatically.
Liveness Probes can be set by defining:

	Liveness command
	Liveness HTTP request
	TCP Liveness probe
	gRPC Liveness probe

Liveness Probe and Command

In the following example, the liveness command is checking the existence of a file /tmp/healthy.

We define a pod that runs the popular busybox container image.
It creates a healthy file upon startup, sleep 30s, remove the healthy file and sleep 600s.
The probe cats the ehalthy file every 5s after an initial delay of 3s.
The first few cat commands will be successful but once the file is removed after 30s, the probe will fail. the kubelet will wait for 3 concecutive failures before declaring the container unhealthy and doing a restart.
In the yaml, the failure threshold is set to 1 meaning after a single failure by the probe, the container is declared unhealthy and the kubelet will restart the container


apiVersion: v1
kind: Pod
metadata:
  labels:
    test: liveness
  name: liveness-exec
spec:
  containers:
  - name: liveness
    image: k8s.gcr.io/busybox
    args:
    - /bin/sh
    - -c
    - touch /tmp/healthy; sleep 30; rm -rf /tmp/healthy; sleep 600
    livenessProbe:
      exec:
        command:
        - cat
        - /tmp/healthy
      initialDelaySeconds: 15
      failureThreshold: 1
      periodSeconds: 5
      
This pod has been created in the terraform step
